# iamWriter

글쓰기에 집중하는 미니멀 마크다운 에디터에, 따라 치고 직접 써보며 익히는 **영어 공부** 모드를 더한 macOS 네이티브 앱입니다. Rust + [iced](https://iced.rs) 로 만들었습니다.

한 창에 두 모드가 있습니다. 타이틀바 오른쪽 버튼이나 단축키로 바꿉니다.

| 모드 | 단축키 | 하는 일 |
|---|---|---|
| **집중 글쓰기** | ⌘1 | 방해 없는 마크다운 편집기 |
| **영어 공부** | ⌘2 | AI 문장이나 유튜브 자막을 한 줄씩 따라 치고, 한국어 뜻만 보고 영작한 뒤 AI 첨삭을 받음 ([typingEng](https://github.com/1ncarnati0n/typingEng) 이식) |

- **설정은 따로 뜨는 창**입니다(⌘, 또는 상태줄의 "설정"). 왼쪽 분류: 화면(테마) · 집중 글쓰기 · 영어 공부 · 단축키. 바꾸면 바로 저장되고 메인 창에 바로 보입니다. Esc나 ⌘W로 닫습니다.
- 테마는 하나입니다. 설정 창의 "화면"에서 고른 테마(자동 · 라이트 · 세피아 · 다크 · 나이트 · Tokyo Night · Tokyo Night Light · Anthropic · Anthropic 다크)를 두 모드가 같이 씁니다.
- 영어 공부 중에 창을 닫아도 저장 안 된 글이 있으면 저장할지 묻습니다.

## 집중 글쓰기

- **포커스 모드** — 지금 쓰는 문단만 또렷하게, 나머지는 흐리게
- **마크다운 강조** — 제목·인용·목록 기호 색 구분, `**굵게**`·`__굵게__`는 Bold(굵은 면이 없으면 시스템 Bold), `*기울임*`은 같은 글꼴의 합성 기울임, `***굵게+기울임***`도 지원
- **글꼴 선택** — 글쓰기용 추천 글꼴(한글 고정폭 · 한글 명조 · 한글 고딕 · 고정폭 · 세리프 · 산세리프) 중 설치된 것만 한국어 이름으로 보여 주고(D2Coding, Monoplex KR, 마루 부리 등), 한글 포함 글꼴엔 `가` 표시. 검색하면 설치된 모든 글꼴에서 찾음
- **한글 대응** — UI 는 Apple SD Gothic Neo 로 통일, Regular 굵기가 없는 글꼴(예: KoPub)도 실제 있는 굵기를 골라 다른 글꼴로 바뀌지 않음, 한글이 없는 글꼴을 고르면 안내, 조합 중인 한글을 본문과 같은 글꼴·같은 줄 위치에 표시(iced 기본 동작은 줄 아래로 처짐)
- **테마** — 자동(시스템 따라감) · 라이트 · 세피아 · 다크 · 나이트 · Tokyo Night · Tokyo Night Light · Anthropic · Anthropic 다크
- **방해 없는 화면** — 타이핑하면 상태 표시줄과 모드 전환 버튼이 사라지고, 마우스를 움직이면 다시 나타남
- **문서 찾기** — ⌘F로 검색, 이전/다음 결과 순환, 현재 결과 강조, Esc로 본문 복귀(대소문자 구분, 한 줄 단위)
- **안전한 저장** — 같은 폴더의 임시 파일에 기록·동기화 후 교체. 시작 파일 읽기 실패 시 경로 분리와 오류 안내
- **설정 창** — 분류별(화면 · 집중 글쓰기 · 영어 공부 · 단축키) 별도 창, 추천 글꼴의 한국어 이름 검색
- 글자 수(공백 제외) · 단어 수 · 읽는 시간을 상태줄 클릭으로 전환. 저장 안 됨 표시는 타이핑 중에도 유지
- 실제 `0` 글자 폭을 측정해 본문 너비 계산
- 실행 취소/다시 실행, 설정 자동 저장, 저장 안 된 글 닫기 보호

## 영어 공부

처음 화면 왼쪽 사이드바에서 기능을 고릅니다. 따라치기 · 직접 쓰기 중에는 사이드바를 숨깁니다.

| 사이드바 | 하는 일 |
|---|---|
| 복습 | 오늘 복습할 문장 수와 **복습 시작**. 카드가 없을 때도 어떻게 생기는지 안내 |
| 영상 | 골라 둔 영어 영상(개발·AI · TED · 이야기)이나 링크를 영어 · 한국어 자막과 함께 보기 |
| AI 문장 | 레벨 · 장르(채팅 · 소설 · Claude Code 프롬프트) · 주제(예시 버튼)로 문장 만들기 → 따라치기 |
| 직접 쓰기 | 보관함의 AI 문장을 고르고 **바로 영작**(따라치기 없이). 첨삭 · 오류 유형 · 다시 쓰기가 여기서 나옴 |
| 보관함 | 영상 · AI 문장 열기와 삭제 |
| 기록 | 누적 줄 수 · 최고 WPM · 틀린 단어 · 실수 유형 |

```
따라치기(유튜브·AI 문장)  →  직접 쓰기  →  첨삭(오류 유형)  →  다시 쓰기
        ↓ 끝낸 문장은 복습 카드로 (다음 날부터)
```

- **AI 엔진** — 문장 만들기 · 자막 정리 · 첨삭을 세 엔진 중 하나가 맡습니다. 설정 창 "영어 공부"에서 엔진과 모델을 고르고 **연결 확인**으로 바로 시험합니다. 고른 엔진 · 모델은 상태줄에 보입니다.
  - **Claude Code** — 로그인된 `claude` CLI. API 키 불필요. 모델: Haiku(최신 별칭, 기본) 또는 아래 Claude 모델
  - **Claude API** — Anthropic API를 직접 호출(쓴 만큼 과금). 키는 macOS 키체인에 저장하고, `ANTHROPIC_API_KEY` 환경변수가 있으면 그것을 먼저 씁니다. 모델: API 키가 있으면 앱을 켤 때 `GET /v1/models`로 **실시간 목록**을 받습니다(설정의 "새로고침"으로 다시 받기). 그중 JSON 스키마 구조화 출력을 지원하는 모델만 보여 줍니다. 키가 없거나 받지 못하면 기본 목록(Haiku 5.5 기본 · Sonnet 5.5 · Opus 5.5 · Fable 5.2 / 5.1 / 5 · Opus 5 · Opus 4.8 · Sonnet 5 · Haiku 4.5)을 씁니다. Claude Code도 같은 목록을 씁니다. Fable · Opus 5.5 · Opus 5 · Sonnet 5.5는 모델이 거절하면 서버가 다른 모델로 다시 시도합니다(`fallbacks: "default"`)
  - **Codex** — 로그인된 `codex` CLI. 모델: `~/.codex/models_cache.json`의 공개 모델 전부(기본은 최신 Terra)
- **AI 문장** — 레벨(A1~B2) · 장르 · 주제를 고르면 영어 8~12줄과 한국어 뜻을 만듭니다. 장르마다 예시 주제 버튼이 있습니다.
  - **Claude Code 프롬프트** — 개발하면서 AI 코딩 에이전트에게 보내는 영어 지시문("Add a unit test for…")을 한 작업의 흐름대로 만듭니다. 예시: 실패하는 테스트 고치기, 다크 모드 추가, 리팩터링, 커밋 메시지와 PR. 직접 쓰기 첨삭은 문법과 함께 프롬프트가 명확한지도 봐 줍니다.
- **따라치기**
  - 맞은 글자는 진하게, 틀린 글자는 빨강, 다음에 칠 글자는 밑줄로 표시합니다.
  - 줄 끝까지 친 뒤 Enter를 누르면 다음 줄로 넘어갑니다. Tab은 건너뛰기(기록 제외), Esc는 그만하기입니다.
  - WPM · 정확도 · 진행을 보여 주고, 틀린 단어를 모아 둡니다.
- **직접 쓰기** — 한국어 뜻만 보고 영어로 씁니다. 교정문, 고친 곳(원문 → 수정 + 이유), 총평, 모범 답안을 받습니다.
- **다시 쓰기** — 첨삭을 받은 뒤 교정문을 가리고 한 번 더 씁니다. 다시 첨삭을 받으면 처음 글 · 다시 쓴 글 · 교정문을 나란히 보여 주고 고칠 곳이 몇 개에서 몇 개로 줄었는지 알려 줍니다.
- **오류 유형** — 고친 곳마다 관사 · 시제 · 전치사 같은 유형이 붙습니다. 이번 글에서 2번 이상 나온 유형 중 최대 2개를 "이번에 집중할 것"으로 먼저 보여 주고, 나머지는 흐리게 둡니다. 유형별 누적은 사이드바 "기록"에 쌓입니다(처음 쓴 글만 셉니다).
- **복습** — 따라치기를 마친 문장은 복습 카드가 되어 다음 날부터 나옵니다. 오늘 복습할 카드가 없으면 **미리 복습**으로 가까운 순 최대 10문장을 먼저 할 수 있습니다. 사이드바 "복습"의 **복습 시작**을 누르면 한 번에 최대 10문장을 한국어만 보고 영작합니다. 첨삭에서 고칠 곳이 나온 문장(구두점만 틀린 건 제외)은 곧 다시 나오고, 맞힌 문장은 라이트너 상자를 한 칸씩 올라가 1 → 3 → 7 → 14 → 30일 간격으로 나옵니다(틀리면 한 칸 아래로).
- **영상으로 공부**
  - 골라 둔 영상 13개(Anthropic의 Claude Code 영상 · 3Blue1Brown · Karpathy · Fireship · TED · Kurzgesagt) 또는 링크로 넣은 영상을 봅니다.
  - yt-dlp로 영어 자막을 받아(자동 생성 포함) 약 10줄씩 세트로 나누고, AI가 세트마다 구두점을 되살리고 한국어 뜻을 붙입니다. 번역은 뒤에서 한 세트씩 진행되고, 번역 전 구간은 영어 자막만 먼저 보입니다. 번역한 자막은 저장되어 다시 볼 때 AI를 부르지 않습니다.
  - 브라우저 플레이어 아래에 지금 문장(영어 · 한국어)과 전체 문장 목록이 나옵니다. 문장을 누르면 그 자리로 갑니다. 영어 · 한국어 가리기, 0.75배, 문장마다 멈춤을 켤 수 있습니다. 키: Space 재생/멈춤 · ←→ 문장 이동 · R 다시 듣기 · K 한국어. 다음에 열면 지난번 본 곳부터 이어서 재생합니다. 처음 한 번 **▶ 클릭해서 연결**을 누르세요.
  - **받아쓰기**(문장 구간만 재생 → 멈춤 → 따라 치기)는 보관함의 영상 "이어하기"나 보기 카드의 "이 영상 따라치기"로 합니다. 다시 듣기 · 0.75배속 · 다음 세트 · 이어하기를 지원합니다.
  - YouTube 요청 제한(429)을 피하려고 자막은 영상당 한 번만 받습니다. Chrome 로그인 쿠키를 쓰고, 막히면 자동으로 다시 시도합니다.
- **보관함** — 만든 문장과 영상(자막·변환한 세트·진행 위치)이 자동 저장됩니다. 다시 열면 AI를 부르지 않습니다.
- **기록** — 누적 줄 수, 최고 WPM, 자주 틀린 단어, 실수 유형을 사이드바 "기록"에 모아 보여 줍니다.
- **설정** — 설정 창(⌘,)의 "영어 공부"에서 AI 엔진, 유튜브 쿠키 사용, 영문·한글 글꼴(따로 고름)을 바꿉니다.
- **보관함 삭제**는 한 번 더 확인합니다(영상은 지우면 자막을 다시 받아야 합니다).

**준비물** (영어 공부 모드를 쓸 때)

```bash
claude        # Claude Code CLI — 처음 한 번 실행해서 로그인
codex login   # 또는 Codex CLI
# 또는 Claude API: 설정 창에 API 키 붙여 넣기 (또는 export ANTHROPIC_API_KEY=…)
brew install yt-dlp   # 유튜브로 연습할 때
```

- 터미널에서 앱을 실행하는 것을 전제로 합니다. `.app`으로 묶어 Finder에서 실행하면 PATH에 이 도구들이 없을 수 있습니다.
- 영상 주인이 다른 사이트 재생(임베드)을 막아 둔 영상은 플레이어에서 재생되지 않습니다.

## 실행

```bash
cargo run --release            # 빈 문서
cargo run --release -- 노트.md  # 파일 열기
cargo run                      # 개발 모드(debug 빌드: 컴파일 빠름, 실행 느림)
```

Rust 1.88+ 와 macOS 가 필요합니다(타이틀바·설정 경로가 macOS 기준).

## 단축키

**공통**

| 키 | 동작 |
|---|---|
| ⌘1 / ⌘2 | 집중 글쓰기 / 영어 공부 |
| ⌘, | 설정 창 (열려 있으면 앞으로) |
| Esc · ⌘W | 설정 창에서 누르면 설정 창 닫기 |

**집중 글쓰기**

| 키 | 동작 |
|---|---|
| ⌘N | 새 글(기존 변경 사항 저장 확인) |
| ⌘O | 열기 |
| ⌘S / ⇧⌘S | 저장 / 다른 이름으로 저장 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |
| ⌘B / ⌘I | 선택 영역 굵게 / 기울임 토글, 선택 없으면 기호 삽입 |
| ⌘⌫ / ⌥⌫ | 커서부터 줄 시작 / 이전 단어까지 삭제 |
| ⌘⌦ / ⌥⌦ | 커서부터 줄 끝 / 다음 단어까지 삭제 |
| ⌘↑ / ⌘↓ | 문서 처음 / 끝 (Shift로 선택 확장) |
| ⌘F | 문서 찾기 |
| Enter / ⇧Enter | 검색창에서 다음 / 이전 결과 |
| Esc | 검색 닫고 본문으로 복귀 |
| ⇧⌘F | 포커스 모드 |
| ⇧⌘D | 테마 순환 |

**영어 공부**

| 키 | 동작 |
|---|---|
| Enter | 줄 끝까지 친 뒤 다음 줄 (유튜브: 빈 칸에서 Enter는 다시 듣기) |
| Tab | 지금 줄 건너뛰기(기록 제외) |
| Esc | 오류 닫기 → 따라치기 중이면 처음 화면 |

## 데이터 위치

| 내용 | 파일 |
|---|---|
| 집중 글쓰기 설정 | `~/Library/Application Support/iamWriter/settings.json` |
| 영어 공부 기록·설정 | `~/Library/Application Support/iamWriter/practice.json` |
| 영어 공부 보관함 | `~/Library/Application Support/iamWriter/practice-library.json` |

- 영어 공부 파일이 없으면 typingEng의 옛 파일(`~/.typing_eng.json`, `~/.typing_eng_library.json`)을 읽습니다.
- 옛 파일은 고치거나 지우지 않습니다(백업). 처음 저장할 때 새 위치에 파일이 생깁니다.

## 개발

```bash
cargo test                       # 단위 테스트 (외부 호출 없음)
cargo test -- --ignored          # 실제 claude / codex / Claude API / yt-dlp 호출 확인 (사용량·과금·네트워크 사용)
cargo install cargo-watch && cargo watch -x run   # 저장하면 자동 재실행
```

테스트 빌드는 설정과 영어 공부 저장소를 프로세스별 임시 폴더에 씁니다. 그래서 어떤 테스트도 실제 데이터를 바꾸지 않습니다.

### 구조

```
src/
```

### 알려진 제한

iced `text_editor` 의 한계로 다음 기능은 아직 없습니다.
- 행잉 제목 기호
- 타자기 모드
- 2px 커서
- 코드 배경색

해결 계획과 전체 디자인 로드맵은 [docs/DESIGN.md](docs/DESIGN.md) 참고.

구현 범위·검증 결과·저장 방식의 제한은 [작업 기록](docs/IMPLEMENTATION.md) 참고.

한영 전환 직후 첫 자모 분리에는 winit의 제한적 재시도 패치를 적용했습니다. 실제 전환 재현 검증은 미완료이며 완전 해결을 보장하지 않습니다. 패치 범위는 [vendor/PATCHES.md](vendor/PATCHES.md) 참고. 이 패치는 영어 공부 모드의 입력칸에도 적용됩니다.
