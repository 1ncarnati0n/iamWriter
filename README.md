# iamWriter

글쓰기에만 집중하기 위한 미니멀 마크다운 에디터. Rust + [egui](https://github.com/emilk/egui) 로 만든 macOS 네이티브 앱.

## 기능

- **포커스 모드** — 지금 쓰는 문단만 또렷하게, 나머지는 흐리게
- **타자기 모드** — 커서가 있는 줄을 항상 화면 가운데에 고정
- **마크다운 강조** — 제목 `#` 은 본문 왼쪽 여백에 걸쳐 표시, `**굵게**` `*기울임*` 은 실제 Bold·Italic 글꼴로
- **글꼴 선택** — 설치된 모든 글꼴 중 검색해서 선택, 한글은 Apple SD Gothic Neo 로 자동 보완, 본문 폭은 글자 수 단위
- **테마** — 자동(시스템 따라감) · 라이트 · 세피아 · 다크 · 나이트
- **방해 없는 화면** — 타이핑하면 상태 표시줄이 사라지고, 마우스를 움직이면 다시 나타남
- 단어 수 · 글자 수 · 읽는 시간 표시
- 설정 자동 저장, 저장 안 된 글 닫기 보호

## 실행

```bash
cargo run --release            # 빈 문서
cargo run --release -- 노트.md  # 파일 열기
```

Rust 1.85+ (edition 2024) 와 macOS 가 필요합니다. 글꼴 경로가 macOS 기준이라 다른 OS 에서는 egui 기본 글꼴로 동작합니다.

## 단축키

| 키 | 동작 |
|---|---|
| ⌘O | 열기 |
| ⌘S / ⇧⌘S | 저장 / 다른 이름으로 저장 |
| ⌘, | 설정 패널 (Esc 로 닫기) |
| ⇧⌘F | 포커스 모드 |
| ⇧⌘T | 타자기 모드 |
| ⇧⌘D | 테마 순환 |

## 개발

```bash
cargo test                       # 단위 테스트
cargo install cargo-watch && cargo watch -x run   # 저장하면 자동 재실행
```

코드는 `src/main.rs` 한 파일에 있습니다. 디자인 개선 계획은 [docs/DESIGN.md](docs/DESIGN.md) 참고.
