# iamWriter

글쓰기에 집중하는 미니멀 마크다운 에디터에, 따라 치고 직접 써보며 익히는 **영어 공부** 모드를 더한 macOS 네이티브 앱입니다. Rust + [iced](https://iced.rs) 로 만들었습니다.

한 창에 두 모드가 있습니다. 타이틀바 오른쪽 버튼이나 단축키로 바꿉니다.

| 모드 | 단축키 | 하는 일 |
|---|---|---|
| **집중 글쓰기** | ⌘1 | 방해 없는 마크다운 편집기 |
| **영어 공부** | ⌘2 | AI 문장이나 유튜브 자막을 한 줄씩 따라 치고, 한국어 뜻만 보고 영작한 뒤 AI 첨삭을 받음 ([typingEng](https://github.com/1ncarnati0n/typingEng) 이식) |

- 테마는 하나입니다. 집중 글쓰기 설정의 테마(자동 · 라이트 · 세피아 · 다크 · 나이트)를 두 모드가 같이 씁니다.
- 영어 공부 중에 창을 닫아도 저장 안 된 글이 있으면 저장할지 묻습니다.

## 집중 글쓰기

- **포커스 모드** — 지금 쓰는 문단만 또렷하게, 나머지는 흐리게
- **마크다운 강조** — 제목·인용·목록 기호 색 구분, `**굵게**`·`__굵게__`는 Bold(굵은 면이 없으면 시스템 Bold), `*기울임*`은 같은 글꼴의 합성 기울임, `***굵게+기울임***`도 지원
- **글꼴 선택** — 글쓰기용 추천 글꼴(한글 고정폭 · 한글 명조 · 한글 고딕 · 고정폭 · 세리프 · 산세리프) 중 설치된 것만 한국어 이름으로 보여 주고(D2Coding, Monoplex KR, 마루 부리 등), 한글 포함 글꼴엔 `가` 표시. 검색하면 설치된 모든 글꼴에서 찾음
- **한글 대응** — UI 는 Apple SD Gothic Neo 로 통일, Regular 굵기가 없는 글꼴(예: KoPub)도 실제 있는 굵기를 골라 다른 글꼴로 바뀌지 않음, 한글이 없는 글꼴을 고르면 안내, 조합 중인 한글을 본문과 같은 글꼴·같은 줄 위치에 표시(iced 기본 동작은 줄 아래로 처짐)
- **테마** — 자동(시스템 따라감) · 라이트 · 세피아 · 다크 · 나이트
- **방해 없는 화면** — 타이핑하면 상태 표시줄과 모드 전환 버튼이 사라지고, 마우스를 움직이면 다시 나타남
- **문서 찾기** — ⌘F로 검색, 이전/다음 결과 순환, 현재 결과 강조, Esc로 본문 복귀(대소문자 구분, 한 줄 단위)
- **안전한 저장** — 같은 폴더의 임시 파일에 기록·동기화 후 교체. 시작 파일 읽기 실패 시 경로 분리와 오류 안내
- **설정 접근** — 카드 전체 스크롤, 닫기 버튼, 추천 글꼴의 한국어 이름 검색, 단축키 안내
- 글자 수(공백 제외) · 단어 수 · 읽는 시간을 상태줄 클릭으로 전환. 저장 안 됨 표시는 타이핑 중에도 유지
- 실제 `0` 글자 폭을 측정해 본문 너비 계산
- 실행 취소/다시 실행, 설정 자동 저장, 저장 안 된 글 닫기 보호

## 영어 공부

```
① 처음 화면          ② 따라치기                    ③ 직접 쓰기
레벨·장르·주제  →  영어 한 줄씩 타이핑        →  한국어 뜻만 보고 영작
또는 유튜브 링크      글자별 맞음/틀림, WPM·정확도     AI 교정 + 한국어 피드백
```

- **AI 엔진** — 문장 만들기 · 자막 정리 · 첨삭을 로그인된 **Claude Code CLI**(최신 Haiku) 또는 **Codex CLI**(최신 Terra)가 맡습니다. API 키는 필요 없습니다. 실제 모델 이름은 상태줄에 보입니다.
- **AI 문장** — 레벨(A1~B2) · 장르(채팅/소설) · 주제를 고르면 영어 8~12줄과 한국어 뜻을 만듭니다.
- **따라치기**
  - 맞은 글자는 진하게, 틀린 글자는 빨강, 다음에 칠 글자는 밑줄로 표시합니다.
  - 줄 끝까지 친 뒤 Enter를 누르면 다음 줄로 넘어갑니다. Tab은 건너뛰기(기록 제외), Esc는 그만하기입니다.
  - WPM · 정확도 · 진행을 보여 주고, 틀린 단어를 모아 둡니다.
- **직접 쓰기** — 한국어 뜻만 보고 영어로 씁니다. 교정문, 고친 곳(원문 → 수정 + 이유), 총평, 모범 답안을 받습니다.
- **유튜브로 연습**
  - yt-dlp로 영어 자막을 받아(자동 생성 포함) 약 10줄씩 세트로 나눕니다. AI가 구두점을 되살리고 뜻을 붙입니다.
  - 브라우저 플레이어가 문장 구간만 재생하고 멈춥니다. 처음 한 번 **▶ 클릭해서 연결**을 누르세요.
  - 다시 듣기 · 0.75배속 · 다음 세트 · 이어하기를 지원합니다.
  - YouTube 요청 제한(429)을 피하려고 자막은 영상당 한 번만 받습니다. Chrome 로그인 쿠키를 쓰고, 막히면 자동으로 다시 시도합니다.
- **보관함** — 만든 문장과 영상(자막·변환한 세트·진행 위치)이 자동 저장됩니다. 다시 열면 AI를 부르지 않습니다.
- **기록** — 누적 줄 수, 최고 WPM, 자주 틀린 단어를 보여 줍니다.
- **글꼴** — 영문(따라치기·입력·작문)과 한글(뜻·첨삭 설명)을 따로 고릅니다.

**준비물** (영어 공부 모드를 쓸 때)

```bash
claude        # Claude Code CLI — 처음 한 번 실행해서 로그인
codex login   # 또는 Codex CLI
brew install yt-dlp   # 유튜브로 연습할 때
```

- 터미널에서 앱을 실행하는 것을 전제로 합니다. `.app`으로 묶어 Finder에서 실행하면 PATH에 이 도구들이 없을 수 있습니다.
- 영상 주인이 다른 사이트 재생(임베드)을 막아 둔 영상은 플레이어에서 재생되지 않습니다.

## 실행

```bash
cargo run --release            # 빈 문서
cargo run --release -- 노트.md  # 파일 열기
```

Rust 1.88+ 와 macOS 가 필요합니다(타이틀바·설정 경로가 macOS 기준).

## 단축키

**공통**

| 키 | 동작 |
|---|---|
| ⌘1 / ⌘2 | 집중 글쓰기 / 영어 공부 |

**집중 글쓰기**

| 키 | 동작 |
|---|---|
| ⌘N | 새 글(기존 변경 사항 저장 확인) |
| ⌘O | 열기 |
| ⌘S / ⇧⌘S | 저장 / 다른 이름으로 저장 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |
| ⌘B / ⌘I | 선택 영역 굵게 / 기울임 토글, 선택 없으면 기호 삽입 |
| ⌘⌫ / ⌥⌫ | 커서부터 줄 시작 / 이전 단어까지 삭제 |
| ⌘⌦ / ⌥⌦ | 커서부터 줄 끝 / 다음 단어까지 삭제 |
| ⌘↑ / ⌘↓ | 문서 처음 / 끝 (Shift로 선택 확장) |
| ⌘F | 문서 찾기 |
| Enter / ⇧Enter | 검색창에서 다음 / 이전 결과 |
| Esc | 검색·설정 닫고 본문으로 복귀 |
| ⌘, | 설정 |
| ⇧⌘F | 포커스 모드 |
| ⇧⌘D | 테마 순환 |

**영어 공부**

| 키 | 동작 |
|---|---|
| Enter | 줄 끝까지 친 뒤 다음 줄 (유튜브: 빈 칸에서 Enter는 다시 듣기) |
| Tab | 지금 줄 건너뛰기(기록 제외) |
| Esc | 오류 닫기, 따라치기 중이면 처음 화면 |

## 데이터 위치

| 내용 | 파일 |
|---|---|
| 집중 글쓰기 설정 | `~/Library/Application Support/iamWriter/settings.json` |
| 영어 공부 기록·설정 | `~/Library/Application Support/iamWriter/practice.json` |
| 영어 공부 보관함 | `~/Library/Application Support/iamWriter/practice-library.json` |

- 영어 공부 파일이 없으면 typingEng의 옛 파일(`~/.typing_eng.json`, `~/.typing_eng_library.json`)을 읽습니다.
- 옛 파일은 고치거나 지우지 않습니다(백업). 처음 저장할 때 새 위치에 파일이 생깁니다.

## 개발

```bash
cargo test                       # 단위 테스트 (외부 호출 없음)
cargo test -- --ignored          # 실제 claude / codex / yt-dlp 호출 확인 (사용량·네트워크 사용)
cargo install cargo-watch && cargo watch -x run   # 저장하면 자동 재실행
```

테스트 빌드는 설정과 영어 공부 저장소를 프로세스별 임시 폴더에 씁니다. 그래서 어떤 테스트도 실제 데이터를 바꾸지 않습니다.

### 구조

```
src/
├── main.rs          앱 셸: 모드 전환(⌘1/⌘2, 타이틀바 버튼), 메시지 전달, 창 닫기·시스템 테마 구독
├── theme.rs         두 모드 공용: 테마 5종, 팔레트, UI 글꼴
├── writer.rs        집중 글쓰기 (+ writer/tests.rs)
└── practice/        영어 공부 (typingEng 이식)
    ├── mod.rs       화면 3개(처음 · 따라치기 · 직접 쓰기)
    ├── claude.rs    Claude / Codex CLI 호출 (JSON Schema 구조화 출력)
    ├── youtube.rs   yt-dlp 자막, 세트 나누기, 문장↔영상 구간 맞추기
    ├── player.rs    127.0.0.1 미니 HTTP 서버 + player.html (YouTube IFrame 플레이어)
    ├── store.rs     기록·보관함 저장(옛 typingEng 파일 읽기)
    └── typing.rs    글자별 판정, WPM, 틀린 단어
```

| 부분 | 내용 |
|---|---|
| `Theme`, `Palette` (`theme.rs`) | 테마 5종. 영어 공부용 보조 글자색 `muted`, 맞음/틀림 `ok`/`bad` 포함(대비 테스트 있음) |
| `inline_spans`, `line_prefix`, `para_lines` | 마크다운 기호 분석과 포커스 모드의 문단 범위 계산(단위 테스트 있음) |
| `Markdown` | `text_editor` 하이라이터: 기호 색, 굵게·기울임 글꼴, 포커스 모드 흐림 |
| `Writer` | 집중 글쓰기 본체: 파일 열기·저장, 실행 취소, 단축키, 화면 구성, 설정 카드 |
| `ImeFix` | 편집기 래퍼: 한글 조합 중 글자(preedit)를 본문 글꼴·같은 기준선에 직접 그림 |
| `Practice` | 영어 공부 본체. 숨어 있을 때 도착한 AI·유튜브 결과는 받아만 두고, 포커스 이동과 재생은 돌아왔을 때 함 |
| `StripCommandText` (`main.rs`) | ⌘ 조합 키 입력에서 글자를 지움. iced 입력칸에 ⌘1·⌘F 같은 단축키 글자가 들어가지 않게 |

- typingEng 이식 설계와 원본에서 달라진 곳은 [docs/TYPINGENG_PORT.md](docs/TYPINGENG_PORT.md)에 있습니다.
- `archive/egui_main.rs` 는 iced 로 바꾸기 전의 egui 버전입니다(빌드에 포함되지 않음).

### 알려진 제한

iced `text_editor` 의 한계로 다음 기능은 아직 없습니다.
- 행잉 제목 기호
- 타자기 모드
- 2px 커서
- 코드 배경색

해결 계획과 전체 디자인 로드맵은 [docs/DESIGN.md](docs/DESIGN.md) 참고.

구현 범위·검증 결과·저장 방식의 제한은 [작업 기록](docs/IMPLEMENTATION.md) 참고.

한영 전환 직후 첫 자모 분리에는 winit의 제한적 재시도 패치를 적용했습니다. 실제 전환 재현 검증은 미완료이며 완전 해결을 보장하지 않습니다. 패치 범위는 [vendor/PATCHES.md](vendor/PATCHES.md) 참고. 이 패치는 영어 공부 모드의 입력칸에도 적용됩니다.
