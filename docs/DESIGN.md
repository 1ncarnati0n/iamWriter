# 디자인 계획

목표는 iA Writer 수준의 **완성도**다. 외형을 그대로 베끼지 않고 원칙만 가져온다.
1. 글자가 곧 UI 다.
2. 화면에 보이는 모든 것은 이유가 있어야 한다.
3. 움직임은 조용해야 한다.

## 기술 기반

- **UI:** [iced 0.14](https://iced.rs) 를 쓴다. 2026-11 에 egui 에서 전환했고, egui 버전은 `archive/egui_main.rs` 에 보관한다.
- **편집기:** `iced::widget::text_editor` 에 마크다운 하이라이터(`Markdown`)를 붙여 쓴다.
- **글꼴:** cosmic-text(fontdb)가 시스템 글꼴을 직접 읽는다. 굵게·기울임 면과 한글 대체 글꼴도 자동으로 찾는다.
- **파일 대화상자:** `rfd` 동기 대화상자를 쓴다.
- **설정 저장:** `~/Library/Application Support/iamWriter/settings.json`

### text_editor 의 한계

| 하고 싶은 것 | 막히는 이유 |
|---|---|
| 제목 `#` 을 본문 왼쪽 여백에 걸치기(행잉) | 글자 간격을 조절할 수 없고, 줄별 위치도 알 수 없음 |
| 타자기 모드 | 줄바꿈된 줄에서 커서의 세로 위치를 알 수 없음 |
| 2px 커서 | 그리기 코드에 1px 이 고정돼 있음 |
| 코드 배경색 | 하이라이트에서 바꿀 수 있는 건 글자색과 글꼴뿐 |

이 넷은 5단계(커스텀 편집기 위젯)에서 한꺼번에 해결한다.

## 단계

### 1단계: 바탕 — ✅ 완료
- 창: `PlatformSpecific { title_hidden, titlebar_transparent, fullsize_content_view }` 를 켠다. 위쪽 30px 영역은 `mouse_area` 로 끌기와 더블클릭을 받는다.
- 시스템 테마: 시작할 때 `system::theme()` 로 읽고, 이후 `system::theme_changes()` 구독으로 따라간다.
- 위젯 색: 팔레트로 `iced::Theme::custom` 을 만들어 슬라이더·버튼·입력창 색을 본문 테마에 맞춘다.

### 2단계: 타이포그래피 — ✅ 대부분 완료
- 굵게는 실제 Bold 면을 고른다. 기울임은 `Oblique`를 내부 신호로 사용해 패치된 렌더러에서 같은 글꼴의 합성 기울임을 적용한다.
- 본문 폭은 `measure`(기본 64) × 현재 글꼴의 실제 `0` 폭으로 계산한다. 한글의 실제 글자 수를 뜻하지 않는다.
- 글꼴 추천: [iA Writer Mono/Duo/Quattro](https://github.com/iaolo/iA-Fonts)는 SIL OFL 로 공개돼 있다. 설치하면 목록에 그대로 뜬다(번들은 하지 않음).

### 3단계: 움직임과 포커스
- 포커스 전환을 부드럽게:
  - 흐린 색을 `Animation` 으로 0.2초 동안 보간한다.
  - 애니메이션이 도는 동안에만 `window::frames()` 를 구독한다.
  - 하이라이터 설정(`HlSettings`)의 색이 매 프레임 바뀌므로 그동안 전체를 다시 칠한다. 문서가 아주 길면 느려지는지 확인한다.
- 문장 단위 포커스:
  - `.` `?` `!` `。` 와 줄바꿈을 문장 경계로 본다.
  - 하이라이터에 줄 범위 대신 (줄, 열) 범위를 넘긴다.
  - 설정에 문단/문장 선택을 추가한다.

### 4단계: 크롬 다듬기
- ✅ 상태 통계는 한 번에 하나, 클릭하면 글자 수 → 단어 수 → 읽는 시간으로 전환한다.
- ✅ 저장 안 됨 안내는 상태줄 왼쪽에 고정 표시한다. 창 제목의 `•`도 남긴다.
- 설정 카드가 나타나고 사라질 때 투명도 애니메이션을 넣는다.

### 5단계: 커스텀 편집기 위젯
`iced_widget::text_editor`(약 1500줄)를 프로젝트 안으로 복사해 그리기와 레이아웃을 고친다. 위 "text_editor 의 한계" 표의 넷을 여기서 되살린다.
- **행잉 `#`:** 제목 줄의 `# ` 를 레이아웃에서 접고, 본문 왼쪽에 따로 그린다.
- **타자기 모드:** cosmic-text 의 레이아웃에서 커서의 실제 y 위치를 얻어 편집기 내부 스크롤을 맞춘다.
- **2px 커서, 코드 배경:** 커서 폭과 배경 사각형 그리기를 추가한다.

유지보수 부담이 생기므로, iced 가 업그레이드될 때마다 원본과의 차이를 다시 맞춰야 한다.

## 검증 방법
단계마다 `cargo run` 으로 직접 보고 스크린샷을 남긴다.
1. 한글·영문이 섞인 긴 글: 한글 입력(IME)과 대체 글꼴을 확인한다.
2. 제목·목록·인용·`**굵게**`·`*기울임*`·`` `코드` `` 가 섞인 문서
3. 테마 5종과 포커스 모드 켬/끔
