# 디자인 계획

목표: iA Writer 와 같은 **완성도**. 외형을 그대로 베끼지 않고 원칙만 가져온다.
1. 글자가 곧 UI 다.
2. 화면에 보이는 모든 것은 이유가 있어야 한다.
3. 움직임은 조용해야 한다.

## 지금 상태와의 차이

| 영역 | 지금 | 목표 |
|---|---|---|
| 창 | macOS 기본 타이틀바(회색 띠) | 타이틀바 투명, 본문 배경이 창 전체를 채움 |
| 커서 | egui 기본(얇은 회색) | 2px 굵기, 테마 강조색, 부드러운 깜빡임 |
| 선택 영역 | egui 기본 파랑 | 테마별 반투명 강조색 |
| 굵게·기울임 | 색만 다름, 기울임은 egui 가 기울여 흉내 냄 | 실제 Bold·Italic 글꼴 파일 사용 |
| 제목 `#` | 본문 열 안쪽에 표시 | 본문 열 **바깥 왼쪽에 걸침**(행잉), 글자 시작선이 흔들리지 않음 |
| 본문 폭 | px 단위 | **글자 수 단위**(예: 64자), 글꼴·크기가 바뀌어도 읽는 리듬 유지 |
| 포커스 모드 | 문단 단위, 즉시 전환 | 문장/문단 선택, 흐려지는 색이 서서히 변함 |
| 스크롤바 | 항상 보임 | 스크롤할 때만 얇게 |
| 설정 | 오른쪽 사이드 패널(egui 기본 스타일) | 떠 있는 카드형 패널, 미리보기 문장, 여백 정리 |
| 상태 표시줄 | 정보를 한 줄에 전부 표시 | 한 가지만 표시, 클릭하면 단어 수 → 글자 수 → 읽는 시간 순으로 바뀜 |
| 테마 | 수동 전환 | 시스템 라이트/다크 자동 추적 + 수동 고정 |

## 단계

### 1단계: 바탕 (작은 변경, 체감 큼) — ✅ 완료
- 창: `with_fullsize_content_view(true)`, `with_title_shown(false)`, `with_titlebar_shown(false)` 를 켠다. 신호등 버튼만 남긴다.
- 커서·선택 영역: `visuals.text_cursor.stroke` 와 `visuals.selection` 을 팔레트에서 가져온다.
- 스크롤바: `ScrollArea` 의 스크롤바 표시 방식을 `VisibleWhenNeeded` 로 바꾸고 `style.spacing.scroll` 을 얇은 floating 스타일로 한다.
- 시스템 테마 추적: `Theme` 에 `Auto` 를 추가하고 `ctx.system_theme()` 를 따른다.

### 2단계: 타이포그래피 (핵심) — ✅ 완료
- 본문 글꼴의 Bold·Italic 파일을 이름 규칙(`X-Bold`, `X Bold`, `X-Italic` …)으로 찾는다. 찾으면 `body-bold`·`body-italic` 패밀리로 등록하고, 없으면 지금 방식(색·가짜 기울임)으로 대체한다.
- 행잉 제목 기호: 제목 줄의 `# ` 를 본문 열 왼쪽 여백에 그린다. 레이아웃에서는 제외하고 painter 로 따로 그린다.
- 본문 폭을 글자 수로: 설정값 `measure`(기본 64)에 `'0'` 글리프 폭을 곱해 px 로 바꾼다.
- 기본 글꼴 추천:
  - [iA Writer Mono/Duo/Quattro](https://github.com/iaolo/iA-Fonts)는 SIL OFL 라이선스로 공개돼 있다. 사용자가 설치하면 목록에 그대로 뜬다(번들은 하지 않음).
  - 설치돼 있지 않으면 SF Mono 를 쓴다.

### 3단계: 움직임과 포커스
- 포커스 모드 전환과 커서 이동 때 흐린 색을 `animate_value` 로 0.2초 동안 보간한다.
- 문장 단위 포커스를 추가한다(`.` `?` `!` `。` 와 줄바꿈 기준).
- 타자기 모드의 스크롤에 부드러운 애니메이션(`scroll_to_rect_animation`)을 쓴다.

### 4단계: 크롬 다듬기
- 설정을 떠 있는 카드(`egui::Window`, 제목줄 없음, 둥근 모서리, 그림자)로 바꾼다. 맨 위에 현재 글꼴로 쓴 미리보기 문장을 둔다.
- 상태 표시줄은 한 가지 정보만 보여 주고, 클릭하면 다음 정보로 바뀐다.
- 저장 안 됨 표시: 제목 옆 `•` 대신 상태 표시줄의 작은 점으로 한다.

### 나중에 (필요해지면)
- 미리보기 모드(렌더링된 마크다운)
- 파일 라이브러리 사이드바
- PDF/HTML 내보내기

## 검증 방법
단계마다 `cargo run` 으로 다음 세 가지 상황을 직접 보고 스크린샷을 남긴다.
1. 한글·영문이 섞인 긴 글
2. 제목·목록·인용이 섞인 문서
3. 테마 4종
