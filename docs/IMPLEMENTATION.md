# UI·UX 및 글쓰기 인터페이스 개선 기록

2026-11-07. 기존 iced 편집기 유지. 의존성 추가 없음.

## 구현 범위

1. **문서 보호**: 시작 파일 읽기 실패를 안내하고 저장 경로를 분리한다. 저장은 같은 폴더의 배타적으로 생성한 임시 파일에 쓰고 `sync_all` 성공 후 `rename`한다. 오류 시 임시 파일 정리. 기존 POSIX 권한과 심볼릭 링크 대상 유지. 읽기 전용 파일은 거부한다.
2. **입력·단축키**: 설정·검색 중 본문 Undo 차단. 소비된 단축키 중 앱 명령만 처리한다. 설정 열면 검색 입력, 닫으면 본문에 포커스를 준다. 연속 삭제는 묶고 동작 종류 변경·커서 이동·선택 영역 교체는 Undo 단위를 분리한다. Tab/Shift+Tab은 위젯이 소비하지 않았을 때 포커스를 이동한다.
3. **설정 접근**: 카드 전체 스크롤, 닫기 버튼, 추천 글꼴 한국어 이름 검색, 결과 없음 안내, 단축키 안내. 설정 항목과 설명에는 본문 가독색을 사용하고 포커스 흐림색과 분리한다. 설정 스키마는 유지한다.
4. **가독성**: 글꼴의 실제 `0` 폭을 측정·캐시해 본문 너비를 계산한다. 글꼴이나 크기를 바꾸면 재측정한다. 좌우 최소 여백은 16px이다. 한글 한 글자는 `0`과 폭이 다를 수 있다.
5. **작성 흐름**: ⌘N은 기존 변경 보호를 재사용한다. ⌘F는 한 줄 단위의 대소문자 구분 검색이다. 결과 수·이전/다음 순환·현재 결과 강조·Esc 복귀를 제공한다. 검색 자체는 본문과 Undo 이력을 변경하지 않는다.
6. **집중·성능**: 상태줄은 글자 수(공백 제외)·단어 수·읽는 시간 중 하나를 보여 준다. 변경 상태는 타이핑 중에도 남긴다. 포커스가 꺼져 있으면 문단 탐색을 생략하고, 켜져 있으면 현재 문단 주변만 읽는다. 매 화면 구성 시 전체 줄을 복사하던 처리를 제거했다.

## 검증

- `cargo test`: 15개 통과, 수동 비교 테스트 1개 기본 제외.
- `cargo test compare_focus_preparation -- --ignored --nocapture`: 별도 실행 통과.
- `cargo clippy --all-targets`: 통과.
- 실제 macOS 창: 빈 문서, 혼합 Markdown 붙여넣기, ⌘F, 한글 검색 결과 3개와 Enter로 2/3 이동, Esc 본문 복귀 확인.
- 현재 검색 결과 색상 강조는 위 UI 확인 뒤 보완했으며 자동 테스트로 검증했다.
- UI 도구 타임아웃 후 창 연결이 사라져 설정·작은 창 검증은 완료하지 못했다.

문단 준비 경로의 작은 비교(디버그 빌드, 21,001줄, 100회): 전체 줄 복사 234.38ms, 현재 문단 탐색 62.46µs. 이 숫자는 화면 렌더링·키 입력 전체 지연이나 포커스 전환 하이라이트 비용을 뜻하지 않는다. 전체 통계 계산과 Undo의 전체 문서 스냅샷은 기존 방식을 유지한다.

## 제한과 위험

- 저장 시 POSIX 권한은 유지하지만 파일 교체로 inode가 바뀐다. 하드 링크 관계와 macOS 확장 속성·ACL 보존은 지원하지 않는다.
- 파일 동기화 후 교체하되 디렉터리 동기화·비정상 종료 자동 복구·외부 파일 변경 충돌 탐지는 제공하지 않는다.
- 텍스트 편집기의 접근성 트리에는 본문 컨트롤이 노출되지 않았다. VoiceOver 검증은 별도 필요하다.
- `block 0.1.6` 의존성에서 기존 Rust future-incompatibility 경고가 남는다.
- 타자기 모드·문장 포커스·애니메이션·미리보기·라이브러리·내보내기는 이번 범위에서 제외했다.

## 입력 문제 후속 수정

- ⌘B/⌘I로 Markdown 기호를 넣거나 제거한다. 한글 선택 유지와 한 단계 Undo를 지원한다.
- `__굵게__`, `***굵게+기울임***`, `___굵게+기울임___`, 이스케이프된 기호를 처리한다. 전체 CommonMark 호환 파서는 아니다.
- 굵은 면이 없는 단일 굵기 글꼴은 시스템 Bold로 강조하고 설정 카드에 안내한다. 기울임 면 부재 시 보통 글꼴로 되돌리던 처리를 제거했다. 한글 대체 글꼴에도 합성 기울임을 적용하도록 iced_graphics를 패치했다.
- ⌘⌫/⌥⌫, ⌘⌦/⌥⌦ 삭제와 ⌘↑/⌘↓ 문서 이동(Shift 선택 포함)을 추가했다. 삭제 Undo는 원래 커서도 복원한다.
- 한글 키보드에서도 앱 단축키를 물리 키 기준 Latin 키로 해석한다.
- winit에 한글 입력기 첫 키의 조합 실패 시 20ms 후 한 번 재시도하는 완화책을 적용했다. 재시도 실패 시 기존 키를 버리지 않는다. 정상 입력이나 비한글 입력에는 지연을 추가하지 않는다. [패치 상세](../vendor/PATCHES.md).
- 테스트 21개 통과(성능 비교 1개 기본 제외), 빌드·Clippy 통과. 한글 Bold의 실제 글꼴 굵기와 기울임 glyph·래스터 이미지 차이를 검사한다.
- 수정판 GUI 실행은 확인했으나 입력 자동화 중 타임아웃과 창 연결 실패가 반복됐다. 실제 한영 전환·후보창·빠른 연속 입력은 미검증이다. IME 재시도 패치의 체감 효과와 첫 키 지연은 실제 타이핑으로 추가 확인해야 한다.
